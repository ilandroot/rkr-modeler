# rkr-modeler (「デジタル粘土　ろくろ モデラ―」 Rotational Clay Modeling Tool)
Version: v1.0.0

## 目的
粘土をヘラで削りながら造形するような、
“プラモデルのような形を造形できるソリッドモデラー” をデジタル上で実現すること。

## 従来方式（BREP）の課題
一般的なソリッドモデラーは BREP（境界表現） を使って形状を記述する。これは、位相データと、幾何データを組み合わせて表現する必要があります。
ヘラで削るたびに BREP を整合性をもって、更新し続ける必要があり、
処理および、データが複雑になり、粘土削って、徐々に、目的形状に近づけるような造形には向かない。

## 新しいアプローチ
もっとシンプルなデータ表現で粘土を表現し、
ヘラで削った形状を軽く扱える方法を考えた。

そこで、Octree によるソリッド表現を採用した。　
この形式データを、ここでは、「デジタル粘土」と呼びます。

## Octree を使うメリット
- 最小単位の立方体サイズを決めるだけでよい

- その範囲内で造形処理が軽くなる

- データが軽量化される

- ソリッド表現が容易になる

- ヘラによる削り加工がシンプルに実装できる

## 実現したかったこと
本来は、粘土を削ってプラモデルのような形状を作るモデラーを作りたかった。
しかし、ヘラの軌跡をどう入力するかという問題にぶつかった。

## 解決策：ろくろ方式
そこで、ろくろのように粘土を回転させ、
ヘラを断面に固定配置して造形する方式を思いついた。

この方式なら、生成できる形状には、制限ができますが以下の利点があります。

- ヘラの軌跡入力が不要

- 回転による造形が自然

- Octree と相性が良い

- 直観的なUIで、誰でも、造形がシンプルに行える

## ダウンロードと起動方法
### 1. GitHub から ZIP ファイルをダウンロード
リポジトリページを開く

右上の 「Code」ボタン をクリック

表示されたメニューから 「Download ZIP」 を選択

ZIP ファイルがダウンロードされる

### 2. ZIP ファイルを展開
ダウンロードした ZIP を任意のフォルダに解凍します。
（Windows なら右クリック → 「すべて展開」）

展開すると、以下のようなフォルダ構成になります：  
rkr-modeler/  
├─ M696.html            # メインの起動ファイル  
├─ LICENSE              # ライセンスファイル  
└─ README.md            # READMEファイル  
  

### 3. M696.html を起動
展開したフォルダの中にある M696.html をダブルクリックします。

ブラウザ（Chrome 推奨）が起動し、
ろくろモデラーの画面が表示されます。

インストール作業やコマンドは不要で、
HTML を開くだけで動作します。
