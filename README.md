# rkr-modeler (「デジタル粘土　ろくろ モデラ―」 Rotational Clay Modeling Tool)
Version: v1.0.1

## 目的
粘土をヘラで削りながら造形するような、
“ソリッドモデラー”（M696） をデジタル粘土データ上でシンプルに実現すること。

## 従来方式（BREP）の課題
一般的なソリッドモデラーは BREP（境界表現） を使って形状を記述する。これは、位相データと、幾何データを組み合わせて表現する必要があります。
ヘラで削るたびに BREP を整合性をもって、更新し続ける必要があり、
処理および、データが複雑になり、粘土を削って、徐々に、目的形状に近づけるような造形には向かない。

## 新しいアプローチ
もっとシンプルなデータ表現で粘土を表現し、
ヘラで削った形状を軽く扱える方法を考えた。

そこで、Octree によるソリッド表現を採用した。　
この形式データを、ここでは、「デジタル粘土」と呼びます。

## Octree を使うメリット
- 最小単位の立方体サイズを決めるだけでよい

- その範囲内で造形処理が軽くなる

- データが軽量化される

- ソリッド表現が容易になる

- ヘラによる削り加工がシンプルに実装できる

## 実現したかったこと
本来は、粘土を削ってプラモデルのような形状を作るモデラーを作りたかった。
しかし、ヘラの軌跡をどう入力するかという問題にぶつかった。

## 解決策：ろくろ方式
そこで、ろくろのように粘土を回転させ、
ヘラを断面に固定配置して造形する方式で実現することにした。

この方式なら、生成できる形状には、制限ができますが以下の利点があります。

- ヘラの軌跡入力が不要

- 回転による造形が自然

- Octree と相性が良い

- 直観的なUIで、誰でも、造形がシンプルに行える

## ダウンロードと起動方法
### 1. GitHub から ZIP ファイルをダウンロード
リポジトリページを開く

右上の 「Code」ボタン をクリック

表示されたメニューから 「Download ZIP」 を選択

ZIP ファイルがダウンロードされる

### 2. ZIP ファイルを展開
ダウンロードした ZIP を任意のフォルダに解凍します。
（Windows なら右クリック → 「すべて展開」）

展開すると、以下のようなフォルダ構成になります：  
rkr-modeler/  
├─ M696.html            # メインの起動ファイル  
├─ LICENSE              # ライセンスファイル  
└─ README.md            # READMEファイル  
  

### 3. M696.html を起動
展開したフォルダの中にある M696.html をダブルクリックします。

ブラウザ（Chrome 推奨）が起動し、
ろくろモデラーの画面が表示されます。

インストール作業やコマンドは不要で、
HTML を開くだけで動作します。

## 使い方（Usage）
### 1. 画面構成
M696.html を起動すると、以下の 2 つのビューが表示されます。  

左側：断面図（2D Canvas）  
粘土の断面（X–Z 平面）を表示します。
カプセル形ヘラ半径、長さ、傾斜角度をパラメータとしてガイド描画されます。  
※注意:カプセル形ヘラとは、円柱の量端部に、半円球を付けた形のヘラのことです。円柱の長さ=0の場合、球形ヘラと同じになります。


右側：3Dビュー（Three.js）  
回転する粘土（Octree ソリッド）が 3D で表示されます。
削り結果がリアルタイムで反映されます。

この「2D 断面図でヘラを配置 → 3D で削り結果を見る」という構造が
ろくろモデラーの最もシンプルで直感的な操作体系です。

### 2. カプセルヘラ（唯一のヘラ）の基本
本アプリでは カプセル形ヘラのみを使用します。

カプセル形ヘラは以下のパラメータを持ちます：

半径（R）

断面内の位置（X, Z）

ヘラを回転させるときの分割数 (steps)

ヘラの長さ カプセルヘラの円柱部分の長さ

ヘラの傾斜角度 0-180の角度を指定する。

粘土の回転による削り軌跡（自動生成）

ヘラは断面図上に 赤い円 として表示され、
その円が「削り領域」を表します。

### 3. 断面図（2D）での操作
断面図はヘラの配置を決めるための UI です。

● 操作内容
クリック：ヘラの配置位置を決める

スライダー：ヘラの半径を変更、回転分轄数、ヘラの長さ、ヘラの傾斜角度

● 表示されるもの
粘土の断面（灰色）

カプセル形ヘラのガイド（赤い円）

削り予定領域のイメージ（赤い円の位置）

断面図は「ヘラをどこに置くか」を決めるための画面であり、
ここでの操作が 3D の削り結果に直結します。

### 4. 粘土の回転（ろくろ機構）
右側の 3D 画面では、粘土が回転しています。

回転速度は右パネルのスライダーで調整可能

回転によってヘラが粘土に接触し、削りが発生

削り結果はリアルタイムで 3D 表示される

ヘラは固定されているため、
粘土が回転することでヘラの軌跡が自動生成される  
という仕組みになっています。

### 5. 3Dビューでの操作
Three.js の標準操作です。

左ドラッグ：視点を回転

右ドラッグ：視点を平行移動

ホイール：ズームイン／アウト

造形中の形状を自由に確認できます。

### 6. 削りの仕組み（内部処理の概要）
粘土は Octree（階層ボクセル）で構成

球形ヘラは「球との交差判定」で削り領域を決定

粘土が回転することで、ヘラとボクセルが交差

交差したボクセルを削除（空にする）

結果が 3D にリアルタイム反映される

BREP のような複雑な境界更新は不要で、
非常に軽い処理で造形が可能です。

### 7. 造形の流れ（最もシンプルな操作例）
断面図でヘラの位置をクリックして決める

ヘラの半径をスライダーで調整する

粘土の回転速度を調整する

3Dビューで削り結果を確認する

必要ならヘラ位置を再調整

造形を繰り返す

完成したら保存（JSON）

この流れだけで、誰でも直感的に造形できます。

### 8. 保存
画面下部の Save ボタンで、
現在の粘土形状（Octree データ）を JSON として保存できます。
